## Decision

The narrow panel uses the space of the A1 grid. It keeps the title and footer. Full Help and the project picker take the work area while open. This keeps long project lists visible and gives the panel one complete area.

| State | Result |
| --- | --- |
| Narrow A1 with panel closed and MIDI connected | Use one status row and two full-width help rows. Keep all 16 pad rows. |
| Narrow A1 with panel open | Show the 16 action cells without the grid. |
| Project picker or full Help | Show the active view. Keep the existing controller actions. |
| Question over the panel | Keep the question in front. |
| Wide A1 | Keep the existing frame. |
| Project picker, Help, or a question closes | Restore the previous panel or grid with the same selection. |

## Open questions

Use two short help rows at 80x26 with an SMC-PAD. The owner gave no row preference. This keeps all 16 pad rows below the current title and grid settings.
