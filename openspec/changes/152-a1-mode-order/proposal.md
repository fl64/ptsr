## Why

A1 Setup can open over Step Edit. The screen shows Setup and the mode line shows Step Edit. Back then closes the hidden editor first.

## What Changes

- Keep one A1 mode open. Show which mode the owner must close first.
- Keep the current edit and cursor when the second mode cannot open.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- patterns: give Step Edit and A1 Setup one order for entry and exit.

## How to check

### Keyboard

1. Open A1. Press F7, then Alt+N. Check the notice and the Step Edit cursor. Press Esc.
2. Press Alt+N, then F7. Check the notice and Setup. Press Enter on Bars to close Setup.

### SMC-PAD

1. Open A1. Hold PAD BANK. Press P6, then P11. Check the notice and Step Edit. Press P1 Back.
2. Press P11, then P6. Check the notice and Setup. Press P1 Back.

### Sound

This change needs no new WAV. It changes which A1 mode can open.
