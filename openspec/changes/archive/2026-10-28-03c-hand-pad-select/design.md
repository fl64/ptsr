# Design 03c

The keymap of the files screen stays as it is; the app reads the file-list actions differently while a file is in hand: up/down/left/right select pads (the same step as on the pads screen), "take / open" (Enter) puts the file on the selected pad through the same path as a pad hit, so the overwrite question of 04c applies. The pad grid of the files screen shows the selected pad as on the pads screen. The note line and the help line say "choose a pad with the arrows, Enter puts it there".
