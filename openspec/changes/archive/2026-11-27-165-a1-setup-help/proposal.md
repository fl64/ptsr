## Why

An absent A1 looks like an existing empty pattern. The overview offers Step Edit even when there is no A1. Setup shows some pad edit cues and the SMC-PAD close cue can name a hold that does not apply.

## What Changes

- Tell the owner when A1 is absent. Show the effective Setup control.
- Use the narrow work area for Setup while it is open. Give A1 Help priority over the command panel at both sizes. Keep the Setup footer with Help open. Show the Setup keys first in Full Help and omit blocked edit actions.
- Show the correct panel close path for Setup and Step Edit.
- Keep the A1 clear question free of underlying edit hints.
- Give the active mode the full status line at 80x26. Show the available E1 role while browsing A1.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- screen-help: name the controls that apply to the active A1 view.

## How to check

1. Open A1 in a new project. Use the shown control to open Setup.
2. Check the Setup rows, short controls and F1. Press Enter on a value row.
3. Check the close cue in Setup and Step Edit with Hold panel on and off.
4. Check the narrow status line while browsing and in Step Edit.

### Sound

This change needs no WAV. It changes screen instructions.
