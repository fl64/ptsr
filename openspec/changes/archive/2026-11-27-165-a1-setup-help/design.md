## Decision

Explain the path from an absent A1 to Setup in the current view. Use the existing input routing to tell which editing actions work during Setup. The controller close cue follows the verified hold status. With the hold off, indicate panel reveal before the close press when the panel is hidden.

| State | Result | Status |
| --- | --- | --- |
| No A1 | Show Setup and recording. | Add |
| Empty A1 | Keep Step Edit available. | Preserve |
| Setup | Use the narrow work area and show row, value, clear and close controls. | Add |
| Setup with F1 | Keep the Setup footer. Put the Setup keys before the general keys. Give A1 Help priority over the command panel. | Add |
| A1 clear question | Show its answer controls. Suppress the regular footer. | Add |
| Verified hold | Name PAD BANK and P1. | Preserve |
| Hold off or unavailable | Name command P1 and the panel if hidden. | Add |
| Narrow Step Edit | Keep the pad action and close control together. | Add |
