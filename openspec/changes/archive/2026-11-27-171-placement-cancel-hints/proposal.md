## Why

Copy, Swap and a file in hand can show a hold instruction when Hold panel is off. P1 first shows the target panel. P1 in its menu goes back to the targets.

## What Changes

- Show the available cancel route in the placement mode line.
- Show `P1 back to targets` when the target menu is open.
- Name pad bank 1 for placement when a hold is unavailable. Keep the full `IN HAND` label in a short mode line.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- screen-help: show the next action and the correct way back while an item is in hand.

## How to check

1. Take a copy, a pad for swap, or a file. With Hold panel off, check the mode line at both supported sizes.
2. In pad bank 2, press P1 to show the target panel. Press P3 for the menu. Press P1 to go back, then P1 to cancel.
3. Repeat the cancel with Esc and with Hold panel on when the controller supports it.

## Sound

This change needs no WAV. It changes placement instructions.
