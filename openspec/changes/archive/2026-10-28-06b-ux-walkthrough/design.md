# Design 06b

- Hint line: on the pads screen, if no pad of any bank has a file, the hint (shown when there is no notice) is "Pads are empty: F6 opens files, Enter takes one, a pad hit puts it there."
- Pad cell: a pad without a file shows "empty"; the info panel of the selected pad shows "empty · test tone A2" (the test tone still plays on a hit, as before).
- F1: rows are grouped under headings in the order of the help line; actions of one kind with numbered keys (banks 1–8) become one row "Ctrl+1…8 · bank 1–8". A heading is a row without keys. Long descriptions are shortened so the box fits 100 columns.
- Pad in hand (Ctrl+X): the pads screen shows "Pad W (think) in hand: arrows choose, Enter swaps, or hit a pad; Esc cancels" in the info panel. While a pad is in hand, Enter (pad mode) swaps with the selected pad instead of switching the mode; arrows move the selection as usual.
- Ctrl+B: on a folder as before; on a file it toggles the folder being shown; the status says "★ breaks: favorite" or "breaks: no longer a favorite".
- MIDI tab: PgUp/PgDn (the bank actions) move the selection to the first row of the previous/next group.
- Settings help: Audio tab — rows, change, tabs, back; Input tab — tabs, back; MIDI tab — rows, groups, learn, clear, tabs, back.
