## Why

Setup on the screens page can leave Settings when Settings is already open. The Files panel names a file for a folder action. F1 omits the Paths tab.

## What Changes

- Let Setup always open or keep Settings.
- Name the favorite action "star folder".
- List Paths in the Settings key help.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- command-panel: keep Settings open and name the folder action.
- screen-help: show all four Settings tabs.

## How to check

### Keyboard

1. Press F12, then F1. Find the Tab row. Check that it lists Paths.
2. Close Help. Press F12 again. Check that Pads opens.

### SMC-PAD

1. Hold PAD BANK, press LEFT and press P11 Setup.
2. Press LEFT and P11 again. Check that Settings stays open and shows its actions.
3. Open Files. Check that P9 says "star folder".

### Sound

This change needs no new WAV. It changes screen selection and labels.
