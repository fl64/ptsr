# Backlog — agreed ideas waiting for their change

Each pending idea needs a separate small change (proposal → spec → code).
[V1.md](plans/V1.md) defines the release scope and order. Only the owner can add work to 1.0.
Every other open idea is `1.x`, including ideas in the broader plans and vision.
Existing completed work stays completed. A `1.x` mark applies only to the remaining work of a partial row.
Project save fixes 86b–86d remain before 87. The callback gate 94a remains before the sequencer.
The broader [plan index](plans/README.md) keeps the designs, not permission to implement all of them before 1.0.
